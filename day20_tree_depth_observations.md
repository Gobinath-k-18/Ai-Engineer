## Concepts Learned

- Gini impurity
- Entropy
- Information gain

## Practical Work
- Trained a DecisionTreeClassifier
- Predicted student Pass/Fail
- Evaluated training and test accuracy
- Visualized the Decision Tree
- Compared max_depth values: 1, 2, 3, and None

## My Observations
- A shallow tree has fewer decision rules.
- A deeper tree can learn more detailed patterns.
- A very deep tree may overfit the training data.
- max_depth limits the tree's complexity.
- This dataset is too small to draw reliable conclusions about real-world performance.

## Conclusion
Decision Trees make predictions using questions and branches.
Tree depth should be selected based on generalization,
not training accuracy alone.
